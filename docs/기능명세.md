# PortfolioAI — 기능 명세서

> **문서 목적**: 화면 구성·UI 방식과 무관하게, 이 서비스가 제공해야 하는 **기능(무엇을 할 수 있어야 하는가)** 을 정의한다.
> Figma 등으로 화면을 새로 설계하더라도 이 문서의 기능이 빠짐없이 담기도록 하는 것이 목표다.

## 아키텍처(현재 방향)

- **프론트엔드**: Figma 기반 React SPA (`Asset Portfolio Performance Analysis/`, `/app` 경로).
- **백엔드**: FastAPI(`webapp.py`) — SPA에는 `/api/app/*` JSON API를 제공하고, 분석 로직은 `pipeline.py` 외 파이썬 모듈이 담당한다.
- **단일화 진행**: 레거시 Jinja2 화면(`web/templates`, `/` 경로)은 Figma React(`/app`)로 통합 후 제거 예정. (자세한 로드맵은 저장소 메모리 참조)

## 1. 서비스 개요

- **목적**: 여러 증권사에 흩어진 주식 보유·거래를 하나로 통합해, 내 투자 성과를 시장 지수(S&P500)와 비교 분석한다.
- **대상 사용자**: 원화·달러 주식을 함께 보유한 개인 투자자.
- **핵심 질문에 답한다**
  1. 내 자산은 지금 얼마이고 어떻게 구성돼 있는가?
  2. 내 투자 수익은 얼마이며, 무엇(주가/배당/환율)에서 났는가?
  3. 내 투자가 지수(S&P500)를 이겼는가?
  4. 투자금 유입·배당·환율 효과를 제거한 **순수 실력**은 어떤가?

## 2. 기능 목록

### A. 계정 · 인증
- **A1** 회원가입(아이디·비밀번호)
- **A2** 로그인 / 로그아웃 / 세션 유지
- **A3** 사용자별 데이터 완전 격리
- **A4** 계정 및 사용자 데이터 삭제

### B. 데이터 수집 · 연동
- **B1** 증권사 Open API 연동(키·시크릿·계좌 등록) → 보유 종목, 거래(주문) 내역, 예수금(원화·달러), 실시간 환율 자동 수집
- **B2** 타 증권사 **거래내역 CSV 임포트**
- **B3** **배당 내역 CSV 임포트**
- **B4** 보유 잔고 CSV / 수동 입력
- **B5** 종목명 자동 보강(티커 → 한글 종목명)
- **B6** 여러 데이터 소스 자동 통합(중복 제거, 소스 우선순위 적용)

### C. 데이터 관리 · 편집
- **C1** 거래 내역 조회 · 추가 · 수정 · 삭제
- **C2** 배당 내역 조회 · 추가 · 수정 · 삭제(추정 배당 → 검증 확정 전환)
- **C3** API 연동 데이터 보정(오버라이드): 원본은 보존하고 사용자가 수정한 값만 덮어씀
- **C4** 임포트 데이터 삭제(증권사별 / 전체)
- **C5** 삭제·편집 직전 **자동 스냅샷** 저장 및 **복구**(되돌리기)
- **C6** 원본 데이터 원장 열람

### D. 자산 현황
- **D1** 총자산 / 주식 평가액 / 예수금(원화·달러) 요약
- **D2** 보유 종목 목록 및 **비중**(포트폴리오 구성)
- **D3** 종목별 현재가 · 평가금액 · 보유수량

### E. 성과 · 손익 분석
- **E1** 손익 구성 분해: **평가손익 / 실현손익 / 배당 / 환차손익**
- **E2** 누적 총손익 및 총수익률(투자원금 대비)
- **E3** 종목별 성과: 투자원금 · 실현손익 · 평가손익 · 수익률 · 상태(보유/청산)
- **E4** 평균단가 회계(분할 매수·매도 정확 반영)
- **E5** 순수 주가손익과 환차손익 분리 표시

### F. 벤치마크(S&P500) 비교 — 핵심 기능
- **F1** 자산 성장 추이 vs S&P500: 같은 시점·금액에 지수를 샀다고 가정해 공정 비교(판 비중만큼 지수도 매도)
- **F2** **시간가중수익률(TWR)** 비교: 투자금(월 납입) 유입 효과를 제거한 "1원당 수익률"로 내 성과 vs 지수
- **F3** **알파**(초과수익) / **베타**(시장 민감도) / **상관계수** — 현금흐름 기반(XIRR)
- **F4** 종목별 알파 · 베타 · 알파기여도 · 베타기여도
- **F5** 롤링 베타 추이(시간에 따른 시장 민감도 변화)
- **F6** 지수 일시투자 시뮬레이션: 특정 시작월에 내 자산을 전부 지수에 넣었을 때 수익금과 내 실제 수익금 비교
- **F7** 연도별 최대/최소 알파 시점 표시

### G. 분석 옵션(계산 파라미터)
> 아래 옵션은 **모든 성과 지표(수익률·손익·알파·베타·차트)에 일관 적용**되어야 한다.
- **G1** 배당 반영 여부 토글 → 켜면 배당을 수익률·알파·손익에 포함
- **G2** 환차손익 반영 여부 토글 → 끄면 달러 자산을 매수평균환율로 고정해 **순수 주가 성과**만 표시
- **G3** 기간 스케일: 1개월 / 3개월 / 6개월 / 1년 / 5년 / 전체
- **G4** 관점 전환: 절대금액(원) ↔ 수익률(%)
- **G5** 범위 전환: 전체 합산 ↔ 개별 종목

### H. 환율
- **H1** USD/KRW 환율 추이
- **H2** 달러 평단가 · 누적 환차손익

### I. 리포트 · 내보내기
- **I1** Excel 내보내기(요약·보유·거래·배당 등 다중 시트)
- **I2** PDF 종합 리포트(요약 · 알파/베타 · 차트 · 보유 상세 분석 · AI 진단)
- **I3** 리포트에 포함할 개별 종목 차트 선택

### J. AI 어시스턴트
- **J1** AI 포트폴리오 진단 · 리밸런싱 제안(알파·베타 관점)
- **J2** 포트폴리오에 대한 자연어 질의응답(Q&A)

## 3. 핵심 계산 규칙(비즈니스 로직)

정확한 성과 비교를 위해 다음 규칙을 반드시 지킨다. (수식·코드 위치는 [성과측정_로직.md](성과측정_로직.md) 참조)

- **벤치마크 비교**는 Modified PME 방식: 내가 판 비중만큼 지수도 매도해 "유령 자본"과 음수 지분을 방지한다.
- **배당**은 반영 시 내 현금흐름(XIRR)에 유입으로 넣어 실제 수익률·알파에 반영한다.
- **환차손익 제거** 시 달러 자산을 보유분 가중평균 매수환율로 고정한다(순수 주가 수익만 남김).
- **투자원금**은 현재 보유분의 매입원가 기준(청산 종목은 실현된 총매수원가)으로 계산한다.
- **베타 회귀**는 실제 거래일만 사용한다(휴장·주말의 평탄 구간 제외).
- **원화 환산**은 거래 발생 당시 환율을 기준으로 한다.
- **배당 데이터**는 검증된 임포트 기록을 우선하고, 없을 때만 추정치를 쓴다.

## 4. 비기능 요구사항

- **보안**: 사용자별 데이터 격리, API 키 안전 보관, 비밀번호 해시 저장.
- **정확성**: 통화·환율·수량 회계의 일관성 보장, 검증 데이터 우선.
- **성능**: 분석 결과를 계산 옵션(배당·환차 조합)별로 캐시.
- **데이터 보호**: 삭제·편집 전 자동 백업 및 복구 제공.
- **확장성**: 새 증권사·데이터 소스를 추가할 수 있는 통합 구조.
- **국제화**: 한국어 UI, 원화·달러 혼합 표기.

## 5. 향후 확장(선택)

- 목표 자산배분 설정 및 리밸런싱 자동 제안 고도화
- 세금·거래수수료 반영
- 알림(목표 도달, 급등락, 배당 지급일)
- 다중 벤치마크(나스닥100·코스피 등) 동시 비교
- 관심 종목(워치리스트) 및 가상 매매
- 리포트에 분석 옵션(배당·환차) 반영
